## About ImperiumMC

**ImperiumMC** is a nations roleplay Minecraft server built around freedom, player choice, and a living world shaped by its community. Enter politics, build a business, grow an industry, participate in warfare, develop cities, or choose a path of your own.

**Server address:** `play.imperium-mc.net`

This repository is the official source for reusable ImperiumMC brand assets. We welcome their use in promotion, videos, streams, reviews, server listings, guides, documentation, and fan content.

## Brand name

Use **ImperiumMC**, with this capitalization and no space.

When MiniMessage formatting is supported:

```text
<gradient:#AA34EA:#4169E1><bold>ImperiumMC</bold></gradient>
```

The primary gradient runs from **Purpura** to **Caeruleus**: `#AA34EA → #4169E1`.

## Brand colors

Latin names are the primary color identifiers; English names are secondary.

| Official name | English | Hex |
|---|---|---|
| **Albus** | White | `#FFFFFF` |
| **Aurum** | Gold | `#F6E0C9` |
| **Ruber** | Red | `#E14141` |
| **Ater** | Black | `#000000` |
| **Caeruleus** | Blue | `#4169E1` |
| **Viridis** | Green | `#69E141` |
| **Purpura** | Purple | `#AA34EA` |

**Purpura** and **Caeruleus** are the primary brand colors. ImperiumMC currently has no official typeface.
