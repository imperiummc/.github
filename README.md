adapt the name and logo.

## Name

Write **ImperiumMC**, with this capitalization and no space.

Where MiniMessage formatting is supported, render the name with the primary gradient:

```text
<gradient:#AA34EA:#4169E1><bold>ImperiumMC</bold></gradient>
```

## Colors

Latin names are the primary color identifiers; English names are secondary. **Purpura** and **Caeruleus** are the
primary brand colors, and the primary gradient runs from Purpura to Caeruleus.

| Official name | English | Hex       |
|---------------|---------|-----------|
| **albus**     | White   | `#FFFFFF` |
| **aurum**     | Gold    | `#F6E0C9` |
| **ruber**     | Red     | `#E14141` |
| **ater**      | Black   | `#000000` |
| **caeruleus** | Blue    | `#4169E1` |
| **viridis**   | Green   | `#69E141` |
| **purpura**   | Purple  | `#AA34EA` |

The same values are available as [JSON](colors/palette.json) and [CSS variables](colors/palette.css).
